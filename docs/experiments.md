# 検証履歴（Experiments）

> 実験の計画と結果。**追記のみ。失敗した実験も消さない。**
> 実験を設計するのは `@idea-chair`。**実行するのはユーザー本人。**
> 結果が出たら `Result` / `Learning` / `Decision` / `Status` を埋めてから、次の分析を回す。

## Status

| 値 | 意味 |
|---|---|
| `PLANNED` | 設計済み・未実行 |
| `RUNNING` | 実行中 |
| `DONE-SUPPORTED` | 実行済み。仮説が支持された |
| `DONE-REFUTED` | 実行済み。仮説が否定された |
| `ABANDONED` | 中止（理由を書く） |

## 詳細

### EXP-001: （実験名）

- **Question**: （知りたいことを1つの問いで）
- **Hypothesis**: （何が起きると予想するか）
- **Why This Matters**: （結果によってどの判断が変わるか）
- **Method**: （具体的な手順）
- **Target**: （対象者の条件と、どこで見つけるか。実在する場所名）
- **Sample**: （必要な人数・件数）
- **Required Time**: （所要時間）
- **Required Budget**: （費用。0円なら0円）
- **Success Criteria**: （事前に決めた数字。例: 5人中3人以上が過去1ヶ月に同じ問題を経験している）
- **Failure Criteria**: （事前に決めた数字。例: 5人中1人以下）
- **Result**: （実行後に記入。**数字と生の発言を書く**）
- **Learning**: （実行後に記入。予想と何が違ったか）
- **Decision**: （実行後に記入。この結果を受けて何を変えるか）
